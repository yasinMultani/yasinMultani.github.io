# Yasin Multani — Portfolio

Modern dark developer portfolio for **Yasin Multani, Senior iOS Engineer | Solution Architect**.

## Stack
- Next.js
- React
- TypeScript
- Static export for GitHub Pages
- Custom CSS

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

The generated static site is in `out/`.

## GitHub Pages
This project is configured with `output: 'export'`. Deploy the generated `out/` directory using GitHub Pages or a GitHub Actions Pages workflow.
